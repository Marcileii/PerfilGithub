# Portfólio — Marcilei Brandão

Portfólio profissional focado em **Desenvolvimento Web, CRM, Automação, Integrações e IA aplicada**.

## Conteúdo

- Apresentação profissional e serviços
- Cases reais corporativos anonimizados
- ServiceFlow como produto público
- Demo interativa de automação e roteamento de leads
- Landing page premium demonstrativa
- Stack técnica e processo de trabalho

## Privacidade dos cases

Projetos realizados em contexto corporativo são descritos apenas pelo problema, arquitetura e tipo de solução. O portfólio não publica nomes de clientes, credenciais, URLs internas, bases, identificadores, código proprietário ou qualquer dado operacional confidencial.

## Publicação

O projeto é estático e compatível com GitHub Pages. Para publicar: **Settings → Pages → Deploy from a branch → main → /(root)**.
